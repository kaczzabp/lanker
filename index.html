SEND FILES TO ANY PC ON YOUR LOCAL NETWORK.

Lanker is a free desktop app for local file transfer. It finds other PCs on your WiFi or Ethernet automatically, asks permission before each transfer, and moves files at full LAN speed. No accounts, no cloud, no USB drives.

FEATURES

Everything Lanker does, and nothing it does not need to do.

»

FULL LAN SPEED

Tuned TCP sockets and 16 MB I/O buffers keep transfers at the limit of your Gigabit connection.

◉

AUTOMATIC DISCOVERY

Broadcasts on your subnet over UDP port 7879, so nearby PCs appear with no manual setup.

#

ACCEPT OR DECLINE

Every transfer starts with a request. The receiver approves it before any file data is sent.

+

FILES AND FOLDERS

Drag files or a full folder into the window, pick a device, and send.

▲

LIVE PROGRESS

Progress and current speed in MB/s stay visible while the transfer runs.

=

PRIVATE BY DESIGN

Traffic stays inside your local network. There is no account and no external server.

INSTALL

Build from source. Use a release build for full transfer speed.

[1] INSTALL RUST

Download the official installer at rust-lang.org/tools/install. On Windows you also need the Visual Studio C++ build tools.

[2] CLONE THE REPOSITORY

git clone https://github.com/kaczzabp/lanker.git
cd lanker

[3] BUILD IN RELEASE MODE

cargo build --release

[4] RUN IT

cargo run --release

The executable is also available at target\release\lanker.exe on Windows.

◉

HOW IT WORKS

Three steps between opening the app and a finished transfer.

  1. 1
    DISCOVERY

    A background task broadcasts UDP packets on your subnet. Other PCs running Lanker listen on port 7879 and appear in the device list.

  2. 2
    HANDSHAKE

    The sender transmits file metadata first. The receiver sees an accept or decline prompt before any file content moves.

  3. 3
    TRANSFER

    After approval, files stream over TCP port 7878 with enlarged socket buffers so the connection, not the software, is the limit.

FAQ

Short answers to common questions.

> IS LANKER FREE?

Yes. It is open source under the MIT License. You can use, modify, and share it freely.

> WHICH SYSTEMS ARE SUPPORTED?

Lanker is developed and tested on Windows. It is written in cross platform Rust, so other systems may work when built from source.

> DO MY FILES LEAVE MY NETWORK?

No. Transfers go directly between PCs on your local network. Nothing is uploaded to the internet.

> DO I NEED AN ACCOUNT?

No. Open the app on two PCs on the same network and they find each other.

> WHERE ARE RECEIVED FILES SAVED?

In the download folder set in Settings. You can change it at any time.
